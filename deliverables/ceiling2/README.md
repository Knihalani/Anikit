## The cross-cutting ceiling (what limits *every* style)

1. **Data-, simulation- and drawing-driven geometry has no first-class home.** All three pieces had to be generated by a Python `build.py`: shader toolkits concatenated (no `#include`), 673 per-frame `draw` layers baked for one morph, a simulation run in 4 ping-pong buffers. An agent can do it, but it is the opposite of a fast, token-cheap spec. The biggest unlocks:
   - a `data` layer (CSV → points, layout morphs, reveal by row, bound text);
   - an agent/particle sim that writes into a field (scatter);
   - a drawn/painted look usable inside shader worlds (brush fills and strokes as GLSL built-ins or a stroke-field filter);
   - a 2D puppet/mesh-warp rig for characters.
2. **Silent failures cost the most iterations.** In order of cost:
   - an unknown font falls back to Inter with no warning, and the `fonts` key is ignored;
   - missing glyphs render as tofu with no warning;
   - a shader NaN blanks the whole frame with no diagnostic;
   - the default 0.5 s crossfade silently shortens films;
   - `iBeat` ignores generated music.
3. **Defaults built for slides, not film or editorial:** crossfade between scenes, centred multi-line text, a critique that flags wordless or shader pieces with false positives, and a CRF that blocks up dark grain.
4. **Performance on the high end:**
   - feedback shaders replay from frame 0 in every parallel chunk (27 CPU-minutes for 10 s);
   - `still --width` and draft change simulation outcomes, so previews mislead;
   - 2D SDF illustration costs 330–430 ms/frame;
   - draft is only about 2× faster on shader specs.
