# 3b · Play: technique tests (sheet.png)

Sheet, left to right, top to bottom: T1 shader turf + vector band (pass 2 frame) · T2 ray-traced 3D band (scene3d, polyhaven HDRI + grass texture) · T4 risograph print filter · T5 type as a window (`matte`) · T3 the band performing an animation (4 frames of a gull's wingbeat).

| test | capability | verdict |
|---|---|---|
| T1 · turf shader + vector band | custom GLSL + 2D | Holds: one sun, long shadows, texture at 100%. Our base. |
| T2 · ray-traced band | **3D (new to me in this film)** | **Can't be made convincing in the time:** primitives read as red bottles ("placeholder-level modelling"), and the HDRI sun gave a dark, muddy exposure. Rejected: illustration is the right fidelity for 144 people seen from the press box. |
| T3 · the band draws a flying gull | motion / drill choreography | **The one that made me stop.** 144 dots reading as a bird whose wings beat makes the band literally a film: the sets are keyframes, the counts are frames. This answers crit 2's IDEA gap ("the formations only lead to a logo"): the formation is now the product's own output, a moving picture made from a written page. |
| T4 · risograph filter | print / graphic | Beautiful as a printed drill chart, but it swaps the palette (blue/pink); it would split the world. Kept out. |
| T5 · ANIKIT as a window onto the night show | type as image (`matte`) | Strong, but it's an overlay on the world, not *in* it. What it taught me: the end word should share one letterform with the painted type. So pass 3 forms the name as the **outline of the same slab face** that paints VIDEO, which answers crit 2's "two type treatments don't match". |

**Surprised me:** how little it takes for a dot outline to read as a living animal once it moves. **Stock:** the riso filter (every agent film has one now). **Engine limit:** quick primitive 3D figures read as placeholders; a band in ray-traced 3D would need real character models.

**Built around:** T3 (the band performs an animation) on T1's world.
