# References and moves

Frame sheets in `refs/sheets/` (judge refsheet, tags product-launch,generative).

1. **Saul Bass / John Whitney, *Vertigo* titles (sheet 01).** Move: one mathematical line figure per section on a flat colour field; type set *beside* the figure as part of the composition; the figure grows by rule. → Our bursts are drawn figures on one flat sky colour; script type sits in the frame like Bass's credits.
2. **Wealthsimple Trade (sheet 03).** Move: one soft, tinted ground; each object centred, generous negative space; a few flat colour accents. → A pale, tinted ground (not cream, not black) and small accent palette.
3. **Japanese hanabi shell catalogues** (outside motion; print). Move: shells drawn as concentric dot rings, labelled by calibre and name in a column. → Each burst is a catalogue drawing; each cue row is its label.
4. **Cai Guo-Qiang, daytime fireworks** (outside motion; art). Move: fireworks *in daylight* become drawing and colour, not light. → Bright ground, bursts as ink.
5. **Linear / Vercel launch films** (`docs/video/craft/launch-visual-craft.md`). Move: real strings in close crops, mono for machine text, strict grid. → The cue list is real spec text, set large and cropped.

**What the good ones do that ours usually don't:** one rule-driven figure language held for the whole film; flat ground with real negative space; type placed as composition, not captions.
**Category cliché to avoid:** fireworks as glowing particles on black (screensaver), AI glows, "neural" nets.
**Closest reference:** Vertigo titles. **Difference:** our figures are driven by timed cue rows that fire on the music, and the rows turn out to be the product's real input.
