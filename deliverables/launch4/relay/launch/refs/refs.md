# Reference work and the moves to steal

Frame sheets: `refs/sheets/` (judge.py refsheet, product-launch + ui-product). The sheet drew mostly 3D BUCK pieces and title sequences — useful for *restraint and single-subject posters* (Wealthsimple Trade: one object per frame on a tinted neutral ground, a single accent; Vertigo: one graphic device that escalates and spirals; BBC World Cup: bold graphic grid). From `docs/video/craft/launch-ai-viral.md` §5:

| Reference | The move (not the look) | How we use it |
|---|---|---|
| Vercel v0 "Generative UI" | a prompt, then output streaming in one continuous shot | The magic shot: the email and its drafted reply in one unbroken shot, then Send |
| Raycast "New Raycast" teaser | cropped fragments of real UI lit like a product; an action list ticks through real tasks | Macro crops of single inbox rows / one draft; the night's task list ticks |
| Pixel 9 Pro teaser | cold open on a typed line over a dark screen, product appears after | Frame 0: the 11:58 p.m. email arriving, a real-sounding line |
| Daylight Computer | sell what it removes | The payoff is the inbox *emptying* |
| Linear Asks | one request carried from one context to another | One thread carried from 2 a.m. (unread) to 7 a.m. (drafted) to sent |
| Saul Bass, Vertigo titles | one graphic device that escalates, then resolves | The clock numerals as the set: they grow, the storm grows, then 07:00 resolves |
| Wealthsimple Trade (BUCK) | one subject per frame, tinted neutral ground, one accent | Every shot has one card / one row as subject; colour lives on the UI |

**Outside motion:** railway departure boards (time as the organising axis), Massimo Vignelli's NYC subway diagram (a strict grid carrying many items), the hotel "do not disturb / wake-up call" card — time-of-day as a design object.

**What the good ones do that ours usually don't:** a single continuous input→output shot held long enough to read; real strings; a camera that follows the cursor/finger in close; sound tied to UI events.

**Category cliché to avoid:** the AI-assistant kit — glowing orb/sparkle icon, purple gradient, "✨ AI" badges, a floating phone mock in space, robot or brain imagery, tiny mono labels over a centred headline.

**Closest reference:** v0's one-shot reveal + Raycast's macro UI. **How we differ:** the whole film is set on a night clock — time is the device that escalates (23:58 → 03:00 storm → 06:59 silence → 07:00), and the ground's light *is* the time of night.
