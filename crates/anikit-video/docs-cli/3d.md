# 3D: `scene3d` (ray-traced PBR)

A physical object in motivated light: a turned ceramic vessel (smooth lathe) in golden-hour sun through leaves (the `golden` rig's gobo) on a sage sweep, an 85 mm lens with breath and focus on the vessel, and light imperfections (proof: docs/video/shots/3d-sets/vessel.jpg). **Vary the world every time:** subject, set, rig, lens and palette all come from the brief. Chrome type on a dark studio is a rejected cliché (BAR.md); use 3D only when the concept is physical.

```json
{ "scenes": [ { "duration": 4, "layers": [ { "component": "scene3d", "props": {
  "env": "cyc", "rig": { "preset": "golden", "warmth": 0.3 }, "set": { "preset": "sweep", "color": "#9DAF94" },
  "camera": { "lens": "portrait85", "shake": "breath", "keys": [
    { "t": 0, "pos": [1.6, 0.9, 7.4], "target": [0, 0.42, 0], "focus": "vessel", "fstop": 2.8 },
    { "t": 4, "pos": [1.1, 0.8, 6.6], "target": [0, 0.42, 0], "focus": "vessel", "fstop": 2.8 } ] },
  "objects": [
    { "type": "lathe", "name": "vessel", "points": [[0, 0], [0.2, 0.01], [0.27, 0.22], [0.2, 0.62], [0.11, 0.78], [0.13, 0.88], [0, 0.88]],
      "material": { "extends": "ceramic", "base": "#EFE6D8", "roughness": 0.35, "imperfections": 0.3 } },
    { "type": "sphere", "radius": 0.13, "pos": [0.62, 0.13, 0.35], "material": { "extends": "clay", "base": "#C8664A" } } ] } } ] } ] }
```

- **Different looks, not just studio chrome:** `"look": "toon|ink|clay|paper|cardboard|gouache"` (an object's `color` tints it; `outline: true|px|{width,color}`); envs `overcast interior city underwater` (caustics). Stills: docs/video/shots/3d-looks/.
- **Practicals:** `lights: [{ pos, target, angle, color, intensity }]` (spots and points); `pos`/`target`/`intensity` may be `"=expr(t)"`, so lights can sweep, track and flicker.
- **Atmosphere:** `fog: { density, color, height: 0.3 }` = ground mist (height fog); `shafts: true` for beams.
- **Build a set:** `"set": "plinth|podium|steps|sweep|field|arches|terrain|landscape"` or `{preset, color, size, density}` (sweep = seamless coloured cyc). Stills: docs/video/shots/3d-sets/.
- **Light it like a set:** `"rig": "rembrandt|loop|clamshell|butterfly|product|high-key|low-key|split|rim|golden|window|top"` or `{preset, ratio, rim, key, angle, height, warmth, gobo: blinds|window|leaves, beam, animate: sweep|reveal, duration}` (animate the light, not just the camera). Camera-relative, set by illuminance ratio. Stills: docs/video/shots/3d-rigs/. Craft: docs/video/craft/3d-design.md.
- `env`: `cyc studio night neon sunset overcast interior city underwater` (or `{preset, color, key, haze}`); `floor`, `bloom`, `exposure`, `tonemap`, `quality: draft|standard|high`.
- **Real-world light and materials (CC0 library, `docs assets`):** `"env": {"hdri": "polyhaven:hdri/studio_small_09", "rotate": 120, "exposure": 0, "background": true|"blur"|false}` lights, reflects and backs the scene with a photographed HDRI (its sun becomes a traced shadow-casting key). `"material": {"texture": "ambientcg:Wood049", "scale": 1}` puts a PBR set (albedo, normal, roughness, AO) on any object, triplanar (no UVs). `{"type": "model", "src": "polyhaven:model/marble_bust_01"}` loads a textured glTF. Find them with `anikit-video assets search <words> --type hdri|texture|model`.
- **Cost:** about 0.5–1.5 s a frame at 1080p. `render --quality draft` (and `still --width`, `critique`) traces at half size automatically; final renders stay full size. Keep 3D shots to 2–4 s.
- Objects: `text box slab plane sphere cylinder torus phone model` (glTF via `src`); `pos rot scale` take `"=expr"` with `t i n`; `keys`, `spin`, `count` (instancing).
- **Make your own geometry** (don't settle for presets): `extrude` `{d: "<SVG path>", height, depth, bevel}` · `lathe` `{points: [[r, y], ...], segments}` · `tube` `{points | path: "=[x(s), y(s), z(s)]", radius: 0.05 | "=expr(s)"}` · `surface` `{x, y, z: "=expr(u, v)", u: [0, 1, 64], v: [...]}` · `heightfield` `{expr: "=f(x, z)", size: [w, d], res}` · `mesh` `{vertices, faces, flat}`. Expressions that use `t` re-tessellate every frame (waves, growing tubes). `{ "script": "..." }` inside `objects` generates objects. Recipe: `examples/video/lookdev/geometry.json`.
- **Imperfections** (nothing real is perfect): material `imperfections: 0.2–0.6` or `roughnessVariation`, `smudges`, `scratches`, `dust`.
- Materials: `chrome glass aluminium gold ceramic plastic rubber matte emissive`, or `{ base, metallic, roughness, transmission, ior, emissive, … }`; textures from compositions.
- Camera: presets `orbit dolly crane static push reveal flyby`, or keyed `pos target focal fstop shutter` (real DOF + motion blur). `lens: wide24|normal50|portrait85|macro100|tele135` (keeps preset framing); `focus: "objectName"` per key = rack focus; `shake: breath|handheld|shoulder|run` (rotational, fraction of frame).
- `check` lints the craft: no rig, turntable orbit (>20°/s), dead locked-off camera, f/<1.4, heavy bloom, floating spheres, >3 hues.
- Particles and physics live inside scene3d: `docs particles`, `docs physics`. Reference: docs/video/components.md#scene3d.
