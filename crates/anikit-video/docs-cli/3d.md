# 3D: `scene3d` (ray-traced PBR)

```json
{ "scenes": [ { "duration": 4, "layers": [ { "component": "scene3d", "props": {
  "env": "studio", "quality": "draft",
  "camera": { "keys": [ { "t": 0, "pos": [-3, 1.2, 6], "target": [0, 0.5, 0], "focal": 40, "fstop": 2.8 },
                        { "t": 4, "pos": [3, 1.0, 5], "target": [0, 0.5, 0], "focal": 50 } ] },
  "objects": [
    { "text": "ANIKIT", "height": 0.7, "material": "chrome", "spin": 10 },
    { "type": "sphere", "radius": 0.35, "pos": [1.8, 0.35, 0.5], "material": "glass" },
    { "type": "box", "count": 40, "size": [0.12, 0.12, 0.12], "pos": "=[cos(i*0.6)*2.5, 0.06, sin(i*0.6)*2.5 - 1]", "material": "gold" } ] } } ] } ] }
```

- `env`: `cyc studio night neon sunset` (or `{preset, color, key, haze}`); `floor`, `bloom`, `exposure`, `tonemap`, `quality: draft|standard|high`.
- Objects: `text box slab plane sphere cylinder torus phone model` (glTF via `src`); `pos rot scale` take `"=expr"` with `t i n`; `keys`, `spin`, `count` (instancing).
- **Make your own geometry** (don't settle for presets): `extrude` `{d: "<SVG path>", height, depth, bevel}` · `lathe` `{points: [[r, y], ...], segments}` · `tube` `{points | path: "=[x(s), y(s), z(s)]", radius: 0.05 | "=expr(s)"}` · `surface` `{x, y, z: "=expr(u, v)", u: [0, 1, 64], v: [...]}` · `heightfield` `{expr: "=f(x, z)", size: [w, d], res}` · `mesh` `{vertices, faces, flat}`. Built once at load, so animate them with `keys`/`rot`/`scale`. `{ "script": "..." }` inside `objects` generates objects. Recipe: `examples/video/lookdev/geometry.json`.
- Materials: `chrome glass aluminium gold ceramic plastic rubber matte emissive`, or `{ base, metallic, roughness, transmission, ior, emissive, … }`; textures from compositions.
- Camera: presets `orbit dolly crane static`, or keyed `pos target focal fstop shutter` (real DOF + motion blur).
- Particles and physics live inside scene3d: `docs particles`, `docs physics`. Reference: docs/video/components.md#scene3d.
