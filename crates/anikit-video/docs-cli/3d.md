# 3D: `scene3d` (ray-traced PBR)

```json
{ "scenes": [ { "duration": 4, "layers": [ { "component": "scene3d", "props": {
  "env": "studio",
  "camera": { "keys": [ { "t": 0, "pos": [-3, 1.2, 6], "target": [0, 0.5, 0], "focal": 40, "fstop": 2.8 },
                        { "t": 4, "pos": [3, 1.0, 5], "target": [0, 0.5, 0], "focal": 50 } ] },
  "objects": [
    { "text": "ANIKIT", "height": 0.7, "material": "chrome", "spin": 10 },
    { "type": "sphere", "radius": 0.35, "pos": [1.8, 0.35, 0.5], "material": "glass" },
    { "type": "box", "count": 40, "size": [0.12, 0.12, 0.12], "pos": "=[cos(i*0.6)*2.5, 0.06, sin(i*0.6)*2.5 - 1]", "material": "gold" } ] } } ] } ] }
```

- **Different looks, not just studio chrome:** `"look": "toon|ink|clay|paper|cardboard|gouache"` (an object's `color` tints it; `outline: true|px|{width,color}`); envs `overcast interior city underwater` (caustics). Stills: docs/video/shots/3d-looks/.
- **Light it like a set:** `"rig": "rembrandt|loop|clamshell|butterfly|product|high-key|low-key|split|rim|golden|window|top"` or `{preset, ratio, rim, key, angle, height, warmth, gobo: blinds|window|leaves, beam}`. Camera-relative, set by illuminance ratio. Stills: docs/video/shots/3d-rigs/. Craft: docs/video/craft/3d-design.md.
- `env`: `cyc studio night neon sunset overcast interior city underwater` (or `{preset, color, key, haze}`); `floor`, `bloom`, `exposure`, `tonemap`, `quality: draft|standard|high`.
- **Cost:** about 0.5–1.5 s a frame at 1080p. `render --quality draft` (and `still --width`, `critique`) traces at half size automatically; final renders stay full size. Keep 3D shots to 2–4 s.
- Objects: `text box slab plane sphere cylinder torus phone model` (glTF via `src`); `pos rot scale` take `"=expr"` with `t i n`; `keys`, `spin`, `count` (instancing).
- **Make your own geometry** (don't settle for presets): `extrude` `{d: "<SVG path>", height, depth, bevel}` · `lathe` `{points: [[r, y], ...], segments}` · `tube` `{points | path: "=[x(s), y(s), z(s)]", radius: 0.05 | "=expr(s)"}` · `surface` `{x, y, z: "=expr(u, v)", u: [0, 1, 64], v: [...]}` · `heightfield` `{expr: "=f(x, z)", size: [w, d], res}` · `mesh` `{vertices, faces, flat}`. Expressions that use `t` re-tessellate every frame (waves, growing tubes). `{ "script": "..." }` inside `objects` generates objects. Recipe: `examples/video/lookdev/geometry.json`.
- Materials: `chrome glass aluminium gold ceramic plastic rubber matte emissive`, or `{ base, metallic, roughness, transmission, ior, emissive, … }`; textures from compositions.
- Camera: presets `orbit dolly crane static push reveal flyby`, or keyed `pos target focal fstop shutter` (real DOF + motion blur). `lens: wide24|normal50|portrait85|macro100|tele135` (keeps preset framing); `focus: "objectName"` per key = rack focus; `shake: breath|handheld|shoulder|run` (rotational, fraction of frame).
- Particles and physics live inside scene3d: `docs particles`, `docs physics`. Reference: docs/video/components.md#scene3d.
