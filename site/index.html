Animation engine · Rust → WebAssembly

anikit

Tweens, springs, timelines, physics, particles, scroll and solid 3D, from one engine with a Rust core compiled to WebAssembly. The knot on this page is rasterised by it on the CPU, without WebGL.

npm i anikit See the demos ↓

TypeScript · Python · MIT

Scroll

One engine.
Seven pieces.

Each piece of the knot carries one part of the library.

01 · Springs

Springs that follow the pointer

Each dot springs towards the one ahead of it. Retargeting keeps the velocity, so the chain never jumps. The buttons are magnetic().

Move the pointer here
spring(dot, { x, y }, { stiffness: 260, damping: 16 })

02 · Text

Split text and stagger

Every character is its own element, and every one starts a little later than the last.

ease: spring
animate(splitText(el).chars, { yPercent: [110, 0] }, { delay: stagger(0.02) })

03 · SVG

Morph and draw

Any path morphs into any other path, with point counts matched in WebAssembly. Strokes draw on and markers ride the path at exact arc length.

timeline().add(path, { d: star(…) }).add(path, { d: circle(…) })

04 · Physics

A physics world in WebAssembly

Rigid bodies with stacking, friction and links. Drag a letter and throw it; click empty space for an impulse.

world({ gravity: [0, 2200] }).dragging()

05 · Particles

100,000 particles

Each particle spring-follows a blend of target shapes through a turbulence field. Simulation, projection and the glow are computed in WebAssembly; JavaScript does one putImageData.

pointCloud(100_000).morph(1, { duration: 2 })

06 · Layout

FLIP layout transitions

Change the layout however you like; flip() animates every element from its old box to the new one with transforms only.

flip('.tile', () => shuffle(grid), { ease: 'spring(bounce: .2)' })
