One flight, no cuts: a tunnel of circuit rings, a neon city on a mirror floor, chrome gates, a knot that shatters in bullet time, a vortex of light — rasterised by anikit's own 3D renderer with camera motion blur, depth of field, lens flares and a shockwave, composed in code and rendered in Node. No browser, no WebGL, no editor.


const film = composition({ fps: 60, duration: 21.8, motionBlur: 1, post: { bloom: 0.85, flares: 0.6, aa: 1 } });
film.scene('velocity', 0, 21.8, {
  timeScale: (t) => bulletTime(t),               // slows everything together
  draw: ({ clock }) => r3.render(path.apply(cam, s(clock)) && cam, items, { mirror, motionBlur }),
});
film.impact(film.timeAt('velocity', HIT), { shake: 34, shockwave: 40 });
// $ anikit-render film.mjs --workers 4
