# Eval briefs (fixed for every round)

Twelve short, natural briefs: subject, length and aspect only, no style hints, one per category. The agent decides the look. Machine-readable copy: `briefs.json` (style tags pick the judge's references). Runner: `scripts/judge_round.py`; procedure: `RUBRIC.md`; results: `ROUNDS.md`.

Every brief is sent with the same short wrapper (`PROMPT` in `scripts/judge_round.py`): build `anikit-video` from current main, read `skills/anikit-video/SKILL.md`, deliver `final.mp4` with sound plus `spec.json` and `stats.json`.
