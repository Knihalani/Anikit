# Pictoplasma 2019 Opener — Character Proxemics — Laurie Rowan / Nexus Studios (2019)

**Why it's in the set: the character-design festival's opener, built from the assets of an interactive holographic installation; the reference for a single strange, layered character carrying an event identity.**

oEmbed: author "Pictoplasma", 33 s (part 1 of four "Character Proxemics" opener uploads on Pictoplasma's Vimeo).

## The idea
Laurie Rowan made a life-size holographic installation: a "tiered totem-like character" that senses proximity and movement and reveals further layers and behaviours as visitors approach along a catwalk; as it grows it adds instrumentation to the hall's soundtrack. Assets for the hologram were also used to create Pictoplasma's 2019 intro (*source*: Nexus Studios). Shown in the INTER__FACES exhibition at silent green, Berlin, May 2019 (*source*: search summary).

## Structure and pacing
A short opener (33 s) in which the totem character grows and reveals layers (*est.* from the installation behaviour); few cuts, steady build (*est.*).

## Typography
Festival name/date as supporting supers (*est.*).

## Colour and light
Hologram-like: saturated, luminous character elements against black (*est.* from holographic installation context).

## Motion techniques
Stacked (tiered) character whose sections each animate their own behaviour; reveals in layers; looping idle cycles (*source* for tiered layers revealed by proximity; loops *est.*).

## Transitions
Growth/reveal of new tiers rather than cuts (*est.*).

## Sound design and music
Each new layer adds instrumentation to the soundtrack (*source*: Nexus, for the installation); the opener likely mirrors this additive build (*est.*).

## What makes it world-class
1. One memorable character is the entire identity.
2. Additive structure: picture and music build layer by layer together.
3. Built from a real interactive installation, so it has internal logic.

## What Anikit would need
- `scene3d`, `camera`, `glow`, `loop` presets, `audio` layered stems with markers.
- GAP: designing and rigging a multi-part character.

## Judge's checklist
- Is there a single, distinctive character or object at the centre?
- Does each visual addition coincide with an audible addition?
- Does the build have a clear escalation to a peak?
- Are loops seamless (no pop at the loop point)?
