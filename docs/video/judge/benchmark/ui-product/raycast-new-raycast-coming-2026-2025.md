# New Raycast. Coming 2026 — Raycast (2025)

**Why it's in the set:** a teaser that makes a launcher (a search bar) feel like a premium physical object: macro close-ups of glass-edged UI over dark, grainy, softly lit forms. Benchmark for "UI as material" and for doing a lot with one UI element.

## The idea
"It's our biggest update yet" (*source*: YouTube description). A teaser for the rebuilt Raycast: the search bar, emoji/quick-pick grid, voice input and AI actions, each shown as an extreme close-up of the UI component.

## Structure and pacing
- 39 s (*source*: YouTube listing); published 18 Dec 2025 (*source*: YouTube).
- 25 % (hq1): extreme macro of the search field: a dark rounded capsule with a 1 px bright rim, the Raycast mark at left, a thick white text cursor and the word "Search" in large grey type cropped by the frame edge.
- 50 % (hq2): a grid of dark rounded tiles with emoji (face-with-hands, fire), the selected tile marked by a copper/orange outline.
- 75 % (hq3): AI agent progress list in white: "Getting active Linear Issues", "Getting active GitHub Issues", "Creating note with summary" (last line dimmed, still running) with app icons, and a prompt bubble "Get my active is…" cut off at top right.
- Thumbnail: glassy capsule with mic icon, white waveform and ↑ send arrow over a blurred black-and-silver abstract surface with a diagonal bright edge line.
- *est.* 15–20 shots, median ≈ 1.5–2 s.

## Typography
UI type at very large scale (a single word "Search" fills a third of frame width), neo-grotesk (Inter, Raycast's UI face, *est.*), grey on dark; secondary list text white at regular weight. Type is part of the UI, not captions.

## Colour and light
Monochrome: blacks to silver greys with film grain; the only accents are emoji colour and one copper selection ring. Light is soft and directional on the abstract backdrop (glossy dark shapes with long gradients) with crisp 1 px rim highlights on the UI capsules (glass edge).

## Motion techniques
- Macro UI: the camera is millimetres from a component, with shallow DOF on the backdrop.
- UI elements treated as glass objects (rim light, translucency over blurred backdrop).
- Live UI states: typing caret, voice waveform, sequential agent steps resolving.

## Transitions
*est.* cuts and short pushes between macro component shots; matched dark backgrounds.

## Sound design and music
Not documented.

## What makes it world-class
1. Extreme scale on a single UI component makes a utility feel like a luxury object.
2. Material on UI: 1 px rim highlights and translucency over a lit, grainy backdrop, so the frame has light and depth (answers BAR.md #5 without forcing 3D type).
3. Real states with real text (agent steps naming real integrations: Linear, GitHub).
4. Strict monochrome with one accent for selection.
5. Grain and soft gradients are motivated by a lit surface, not a blob backdrop.

## What Anikit would need
- `composition` UI components at large scale; `camera` macro push; backdrop as `scene3d` glossy surface or `shader` with soft light, `component` "grain"; `post` with grain; `text` typing caret.
- GAP: glass UI material (backdrop blur + refraction + rim highlight) as a layer style.

## Judge's checklist
- Is a single UI component shown at macro scale, filling the frame, with crisp text?
- Do UI surfaces have material (rim light, translucency) over a lit backdrop?
- Are states real and specific (typing, waveform, named agent steps)?
- Is the palette monochrome with at most one accent?
- Is grain present but fine, without banding in the dark gradients?
