# What is GitHub? — BUCK (2022)

**The modern big-brand explainer: four chapters, four rendering styles (live action, 3D, cel, 2D motion graphics), held together by one comic host and one rubber duck.**

## The idea
GitHub wanted an updated, value-based brand story that would delight existing developers and introduce the platform to newcomers (*source*: European Design Awards entry). BUCK built it on "rubber duck debugging" (explaining a problem aloud to a duck): comedian Phil Wang, as GitHub's "Geeky Powerhouse" persona, talks to a custom 3D-printed rubber duck (*source*: buck.co). Four chapters (*source*): a short technical how-to, a showcase of projects and developers, GitHub's cultural relevance, and its future ambitions. Each uses a different style.

Length: not available from oEmbed (`null`); it runs past 90 s (*est.*: four chapters). Analyse 60 s spanning the cut from live action into the first animated chapter.

## Structure and pacing
- Chaptered; within chapters, quick comic cuts (*est.* median 1.5–2.5 s from the host-led format).
- Style switches at chapter boundaries are the main structural beats (*source*: chapter/style list).

## Typography
Title frame (*observed*, buck.co hero still): "What *is*… GitHub?" set in a grotesk (Mona Sans–like, *est.*; GitHub's own typeface family), heavy weight for "What" and "GitHub?", light italic for "is…", composited in the live-action plate beside Phil's head, each word in a pastel gradient (mint → green for "What", yellow → amber for "GitHub?"). Scope letterbox (black bars) over a 16:9 frame. Code appears as real, legible code (GraphQL query, Octokit auth snippet) in a monospace in the illustrated frames (*observed*).

## Colour and light
- Live action: warm office, shallow depth of field, a blue jacket with red cuff as the host's colour signature (repeated in the cel caricature in hq2.jpg — *observed*).
- 2D illustration (*observed*, a328408b still): magenta/violet face, cyan and mint background ribbons, acid-yellow streaks, heavy airbrush grain, iridescent reflections in glasses; code overlaid in blue/purple. Sky blue cel frames with soft clouds (hq2).

## Motion techniques
Cel animation (8 cel animators, *source*), 3D with rigging and lighting, 2D After Effects animation, FX — all credited (*source*). Kinetic type composited into live plates. *est.*: code types on; ribbons flow.

## Transitions
Hard cuts for comedy timing; chapter changes as style switches. *est.*

## Sound design and music
Antfood (music and sound, *source*). VO-led by the host; comic timing in the edit (editor Benjamin Putland, The Panics — *source*).

## What makes it world-class
1. One concept (the duck) motivates the host, the props and the brand system (BUCK reused the duck for GitHub Universe 2023, *source*).
2. Style changes carry structure: each chapter's medium matches its content (how-to = clean, showcase = rich illustration, future = 3D).
3. Real content on screen: actual code, not grey placeholder lines.
4. Type composited into a live plate with gradient fills that echo the brand palette.
5. Comic timing: performance and edit make a dry topic watchable.

## What Anikit would need
`video` plates with `text` composited (gradient fills, mixed weights/italic), letterbox, `component: code` for real code, `image` illustration plates with `post` grain, `scene3d` for duck/3D chapter, `camera` moves. GAP: cel character acting; airbrushed grain-gradient illustration as a native renderer.

## Judge's checklist
- Does each section's visual style serve its content, with clear chapter changes?
- Is on-screen content real (legible code, real UI) rather than placeholder bars?
- Does type sit in the image (integrated, with depth and colour) rather than float as a caption card?
- Is there one recurring motif that holds different styles together?
- Is comic or emotional timing in the edit, not just information?
